| `acp/` | 访问控制策略相关，包含客户端、服务器、策略等 |

## 技术栈

- **后端**: TypeScript, Node.js
- **前端**: TypeScript, Vite
- **测试**: Vitest
- **构建工具**: pnpm, TypeScript, Vite
- **部署**: Docker, Fly.io
- **移动应用**: Android, iOS, macOS

## 核心功能

1. **多渠道通信**: 支持 Discord、Slack、Telegram、Signal、LINE、iMessage 等多种通信渠道
2. **代理系统**: 提供智能代理功能，处理各种任务
3. **插件系统**: 支持扩展功能，通过插件实现自定义能力
4. **技能系统**: 提供各种技能模块，如天气、GitHub、Notion 等
5. **媒体处理**: 支持音频、图片等媒体文件的处理
6. **定时任务**: 内置 cron 系统，支持定时执行任务
7. **安全系统**: 包含访问控制、密钥管理等安全功能
8. **网关服务**: 提供统一的网关服务，处理各种请求
9. **Web 界面**: 提供 Web 控制界面，方便管理和监控

## 项目特点

1. **模块化设计**: 采用模块化架构，各功能模块独立开发和维护
2. **多平台支持**: 支持 macOS、iOS、Android 等多种平台
3. **多语言支持**: 文档支持英文、日文、中文等多种语言
4. **可扩展性**: 通过插件和技能系统，支持功能扩展
5. **安全性**: 内置安全机制，保障系统安全
6. **可靠性**: 完善的测试体系，确保系统稳定运行

## 开发流程

1. **安装依赖**: 使用 pnpm install 安装项目依赖
2. **开发模式**: 使用 pnpm dev 启动开发模式
3. **构建项目**: 使用 pnpm build 构建项目
4. **运行测试**: 使用 pnpm test 运行测试
5. **代码检查**: 使用 pnpm check 进行代码检查和格式化

## 部署方式

1. **本地部署**: 直接运行构建后的代码
2. **Docker 部署**: 使用 Dockerfile 构建容器
3. **Fly.io 部署**: 使用 fly.toml 配置部署到 Fly.io
4. **移动应用**: 构建并安装对应平台的应用

## 总结

OpenClaw 是一个功能强大、架构清晰的项目，采用现代化的技术栈和模块化的设计理念。项目支持多种通信渠道、插件扩展、技能系统等核心功能，可在多种平台上运行。通过清晰的目录结构和组织方式，使得项目易于维护和扩展。
